# Marlow: Coffee & Bakehouse

A demo website for a fictional neighbourhood coffee house and bakehouse. It is an editorial, heavily animated single page built with Vite, vanilla JS, GSAP (ScrollTrigger, SplitText, Flip), Lenis smooth scroll and three.js.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Features

- **Preloader:** a cup filling in sync with a counter, then a curtain reveal.
- **Hero:** WebGL steam shader over the photo and a split-text headline.
- **Ticker:** a marquee whose speed reacts to scroll velocity.
- **Story:** a pinned manifesto that fills word by word as you scroll.
- **Bean to cup:** a horizontal scroll through four steps.
- **Menu:** tabs with Flip transitions and a dish image that follows the cursor.
- **Gallery:** multi-speed parallax columns with a lightbox.
- **Reviews:** rotating quotes.
- **Visit:** a live open/closed badge, a map that draws itself and a reservation form.
- **Footer:** a giant interactive wordmark.
- **Throughout:** custom cursor, magnetic buttons, reduced-motion support and responsive layouts.

Photos are from Unsplash (see `public/images/credits.json`). The business, contact details and reviews are fictional.
